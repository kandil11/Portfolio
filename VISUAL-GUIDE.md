## 📱 Mobile vs Desktop

### Desktop (1024px+)
- Custom cursor visible
- Asymmetric multi-column grids
- Larger typography
- More spacing

### Mobile (< 768px)
- Standard cursor
- Single column layouts
- Responsive typography
- Compact spacing
- Touch-friendly buttons

---

## 🎬 Animation Flow

### On Page Load:
1. Navigation fades in (0.2s delay)
2. Hero name appears (0.4s delay)
3. Info cards slide in (0.6s delay)
4. Scroll indicator pulses

### On Scroll:
1. Background color transitions
2. Sections fade in from bottom
3. Project cards appear with stagger
4. Skill bars fill progressively
5. Timeline items slide from left

### On Hover:
1. Cursor scales up
2. Buttons attract cursor
3. Project borders light up
4. Description reveals
5. Tech pills highlight

## ✨ Special Effects

### Grain Overlay
```
Fixed layer on entire page
Opacity: 5%
SVG noise filter
Adds tactile, film-like quality
```

### Neon Glow
```
Text-shadow with multiple layers
Blue glow: 0 0 10px rgba(cyan, 0.5)
Wider glow: 0 0 20px rgba(cyan, 0.3)
Widest: 0 0 30px rgba(cyan, 0.2)
```

### Parallax
```
Hero background moves at 50% scroll speed
Creates depth effect
Smooth with transform3d
```
